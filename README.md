# RustChain LangGraph Template
LangGraph templates for RustChain ecosystem integration

## Requirements

```txt
langchain>=0.3.0
langchain-core>=0.3.0
langgraph>=0.2.0
requests>=2.31.0
python-dotenv>=1.0.0
```

## Installation

```bash
pip install -r requirements.txt
```

## Usage

```python
from rustchain_tools import RustChainTools

# Initialize tools
tools = RustChainTools()

# Use in LangGraph
# See examples/ directory for complete workflows
```
